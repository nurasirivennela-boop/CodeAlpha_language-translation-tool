# 🌐 Language Translation Tool

A simple and user-friendly **Language Translation Tool** developed using HTML, CSS, and JavaScript. The application allows users to translate text between multiple languages using the MyMemory Translation API.

## 🚀 Live Demo

[Click here to view the Live Demo](https://nurasirivennela-boop.github.io/CodeAlpha_language-translation-tool/)

## ✨ Features

- 🌍 Translate text between multiple languages
- 🔄 Swap source and target languages
- 📋 Copy translated text
- 🔊 Text-to-speech functionality
- 🗑️ Clear input and output text
- 📱 Responsive design for different screen sizes
- ⚡ Real-time translation using an API
- 💬 User-friendly interface

## 🛠️ Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling and responsive design
- **JavaScript** – Functionality and API integration
- **MyMemory Translation API** – Text translation
- **Web Speech API** – Text-to-speech functionality
